Why spans, not one-bit classifiers




Binary guards face a dilemma: block the document and the agent loses data it needed,
or pass it and the attack goes through. spanguard returns character spans, so both
failure directions are measured — and published — separately:


    

  • escape rate — attack text still readable after the guard (lower is better)
    • 

  • over-stripping — benign data destroyed on clean documents (lower is better)
    • 



Every number is a committed run record you can re-verify; CI fails on regression.
